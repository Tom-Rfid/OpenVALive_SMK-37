# 01 — Overview

**OpenVALive SMK-37** is a live-first firmware for the M-VAVE SMK-37 Elite and Pro, built on M-VAVE's open kit
`smk37_open`. It plays the OpenVALive instrument ([OpenVALive CORE](https://github.com/Tom-Rfid/OpenVALive_CORE), the `va/` submodule) with the
SMK-37's keys, pads, faders, wheels and MIDI OUT.
