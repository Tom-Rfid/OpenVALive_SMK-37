# 01 — Présentation

**OpenVALive SMK-37** est un firmware pensé pour le live, pour les SMK-37 Elite et Pro de M-VAVE, bâti sur le kit
ouvert de M-VAVE `smk37_open`. Il joue l'instrument OpenVALive ([OpenVALive CORE](https://github.com/Tom-Rfid/OpenVALive_CORE), le sous-module `va/`)
avec les touches, pads, faders, molettes et le MIDI OUT du SMK-37.
